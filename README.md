# weldwasm

Weld numeric wasm values, ranges, and human-readable units.

**Site:** https://theworker02.github.io/weldwasm/

## Install / run

```bash
git clone https://github.com/theworker02/weldwasm.git
cd weldwasm
node src/cli.js
node --test
```
